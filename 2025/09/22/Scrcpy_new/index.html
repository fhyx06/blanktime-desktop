2025年09月22日# Scrcpy

Scrcpy: 开源的高性能工具，它允许你通过 USB 数据线或 WiFi 网络，在电脑上实时显示并控制你的安卓手机或平板设备

推荐版本

2026年3月23日

目前已经有 第三方带 GUI 界面的版本，EScrcpy

  1. 可视化交互： 将复杂的命令行参数（码率、帧率、旋转等）转化为直观的滑块和开关，不再需要手动输入代码。
  2. 环境集成： 软件通常内置了最新的 ADB 环境和 Scrcpy 核心内核，省去了配置系统环境变量的步骤，真正做到“解压即用”。
  3. 多设备管理： 支持同时连接多台手机，并能在界面上快速切换或开启多个窗口，非常适合需要多机协同的用户。

当然，若有兴趣也可以使用 QtScrcpy

详情查看 https://github.com/barry-ran/QtScrcpy/blob/dev/README_zh.md

2025年9月22日

这个版本是原生 Scrcpy，也就是本帖的基础推荐版本。

  1. 极简主义： 没有 UI 界面，启动速度极快，系统资源占用几乎可以忽略不计。
  2. 硬核极客： 适合有一定命令行基础的用户，通过自定义 .bat 脚本可以实现极高程度的自动化控制。
  3. 极致稳定： 作为所有 GUI 版本的“心脏”，原生版在长连接和大规模数据传输时拥有最稳定的表现。

特性

  • 轻量： 原生体验，仅显示设备屏幕画面
  • 性能： 帧率 30~120fps (视设备性能而定)
  • 画质： 分辨率 1920×1080 或更高
  • 低延迟： 延迟<70 毫秒
  • 启动快： 约 1 秒显示首帧画面
  • 无残留： 安卓设备上不安装/不遗留任何文件
  • 用户获益： 无需账户、无广告、不联网也能用
  • 自由开源： 免费的自由开源软件 (FOSS)
  • 更多： 请查看官方文档（没有特殊手段会很慢）

前期准备

  • 首先启用 USB 调试 (在手机上)： 进入 设置 -> 关于手机 -> 连续点击 版本号 数次，直到提示 您已处于开发者模式 。接下来我们开启 USB 调试 ，连接电脑时，手机屏幕上可能会弹出 允许USB调试吗？ 的授权框，勾选 始终允许 并确认。
  • 安装 ADB 驱动（Windows）： 官方 SDK Platform-Tools (包含 adb)
  • 接下来需要获取Scrcpy到本地： Github链接
  • 选择对应系统下载便好！（接下来Windows举例）。
  • 解压压缩包会发现 scrcpy.exe ，一会儿要用的。

基础使用 (USB 连接)

  • 连接手机： 用 USB 数据线将手机连接到电脑。确保手机 USB 连接模式为传输文件或仅充电（只要能触发 adb 连接即可）。
  • 首次连接授权： 手机弹出 允许USB调试吗？ 时，勾选 始终允许 并点击 确定 。
  • scrcpy 启动！(大声)： 双击运行解压后文件夹里面的 scrcpy.exe 。
  • 然后你的电脑上应该就会弹出手机画面窗口

进阶使用 (WiFi 连接)

  • 手机和电脑必须连接同一个 WiFi 网络。
  • 先用 USB 线连接手机和电脑。
  • 在scrcpy目录上面的路径显示框中输入cmd，然后回车即可，届时会弹出“命令提示符”窗口。
  • 用 USB 数据线将手机连接到电脑，届时在cmd窗口输入 “.\scrcpy.exe --tcpip” 后拔掉数据线即可。
  • 后续便可以直接使用 “.\scrcpy.exe -e” 进行局域网连接。
