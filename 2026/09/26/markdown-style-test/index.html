2026年09月26日# Markdown# 主题测试

这是一篇用于检查 BlankTime 桌面主题的排版样本。你可以拖动窗口、调整大小、切换最大化，并点击右侧目录，观察不同宽度下的阅读效果。

文中包含基础 Markdown、常见 HTML 和现有 Volantis 标签的兼容示例。数学公式已启用渲染；Mermaid 仍保留为后续功能的测试样本。

01 · 段落与文字

午后的桌面安静下来，窗外的树影慢慢挪动。打开一篇文章，就像从抽屉里拿出一本写了一半的笔记：有认真记录的步骤，也有暂时没想明白的问题。文字应该有呼吸的空间，段落之间保持适当距离，阅读时不必刻意寻找下一行。

这是第二个自然段，用于检查段间距。中文与 English 混排、数字 0123456789、版本 v1.2.3、时间 20:30，以及标点「引号」、（括号）、破折号——与省略号……都应该清晰可辨。

粗体文字用于强调。 斜体文字用于补充。 粗斜体同时出现。 这段文字已经被划掉。

行内代码：npm run dev、source/_posts/、const message = "你好";。

以下使用 HTML 扩展：下划线、高亮标记、H2O、x2、小号补充文字。

第一行，末尾有两个空格。
第二行应紧接上一行换行，而不是成为新的段落。

特殊字符应按原样显示：&、<article>、>、©、→、✓。Emoji：🌿 🎧 📁 📝。

12 · 阅读检查清单

  • 文章标题、日期和标签显示正确，原始配置没有出现在正文中。
  • 各级标题的字号与间距清晰，右侧目录层级正确。
  • 点击目录可以定位，滚动后当前章节会高亮。
  • 超长链接能换行，代码和宽表格可以在内部横向滚动。
  • 图片保持比例，没有超出文章区域。
  • 原生折叠块和旧主题折叠块均可展开，内容没有泄漏到折叠块外。
  • 顶部工具栏右侧可切换明暗模式和目录显示，刷新后保留选择。
  • 底部字数与阅读进度正常显示。
  • 手机端可以展开目录，正文没有被侧栏挤出窗口。
